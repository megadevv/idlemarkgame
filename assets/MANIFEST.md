## Asset Loading Strategy
1. **Critical Assets (Load First)**:
   - Default background (calm_ocean.jpg)
   - Wooden boat, rusty hook
   - Common fish (5 species)
   - Core UI buttons (cast, upgrade, shop)
   - Currency icons (coin, gem)
   - Navigation icons

2. **Secondary Assets (Load on Demand)**:
   - Other backgrounds
   - Locked boats and hooks
   - Rare/epic/legendary fish
   - Booster icons
   - Tier badges
   - Special buttons

3. **Lazy Loading**:
   - Event fish (only during events)
   - Premium items (only when shop opened)
   - Seasonal content

## File Format Guidelines
- **JPG**: Backgrounds only (no transparency needed)
- **PNG**: All sprites, icons, UI elements (transparency required)
- **SVG**: Navigation icons (scalable, small file size)
- **WebP** (alternative): Consider for better compression if browser support allows

## Optimization Techniques
- Use sprite sheets for animations
- Implement texture atlases for fish collections
- CDN delivery for faster loading
- Progressive loading (low-res → high-res)
- Preload critical assets
- Lazy load non-critical assets
- Cache aggressively (service workers)
