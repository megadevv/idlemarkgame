# Placeholder Asset Files

This directory contains placeholder files that demonstrate the expected structure.
Actual visual assets should replace these placeholders.

## How to Replace Placeholders

1. Create or commission visual assets according to specifications in README files
2. Ensure assets match exact dimensions and format requirements
3. Replace .placeholder files with actual image files
4. Maintain the same naming convention
5. Test assets in-game for proper rendering

## File Naming Pattern

```
[category]_[name]_[variant].placeholder

Examples:
- calm_ocean.placeholder → calm_ocean.jpg
- wooden_boat.placeholder → wooden_boat.png
- common_bubblefin.placeholder → common_bubblefin.png
```
