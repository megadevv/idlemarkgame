# Fish Sprites Specification

## Overview
Fantasy fish sprites with varying rarity tiers for the Hooker fishing game.

## Requirements
- **Format**: PNG with transparency
- **Standard Dimension**: 128×128 pixels
- **Legendary Dimension**: 256×256 pixels
- **Style**: Cartoonish, fantasy ocean creatures
- **Optimization**: Standard <30KB, Legendary <80KB

## Technical Specifications
- Transparency: Required alpha channel
- Orientation: Swimming left to right (facing right)
- Animation Ready: Single frame, but designed for potential animation
- Center Point: Middle of body mass
- Shadow: Optional subtle drop shadow

## Design Guidelines
- Each rarity tier should have clear visual distinction
- Common: Simple, earthtone colors
- Uncommon: Brighter colors, more detail
- Rare: Special features (glow, patterns)
- Epic: Magical effects, complex design
- Legendary: Imposing, multiple special effects
- All fish should be immediately readable at size
- Maintain consistent cartoonish art style
- Fish should look appealing but catchable
